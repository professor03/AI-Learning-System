# Contributing

This is a student research prototype. Focus contributions on reproducible fixes, tests and documentation rather than unverified feature claims.

1. Create a branch from the latest `main`.
2. Run `npm ci`, `npm test` and `npm run build`.
3. For user-flow changes, also run `npm run test:e2e`.
4. Do not commit `.env`, API keys, personal learning files, camera footage or generated build output.
5. In the pull request, state what was tested and which limitations remain.

Claims about AI quality, person detection, attention or learning outcomes require an explicit dataset, evaluation method and results. Passing interface tests alone is not sufficient evidence.

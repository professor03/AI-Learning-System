# AI Learning System Demo Checklist

## 建議展示流程（約 3 分鐘）

### 1. 建立學習材料
- [ ] 匯入一份課程 PDF 或貼上教材文字
- [ ] 確認系統顯示材料名稱與內容摘要
- [ ] 說明系統會以教材內容作為後續問答與出題依據

### 2. AI 生成學習內容
- [ ] 產生繁體中文摘要
- [ ] 產生關鍵概念與名詞解釋
- [ ] 產生 3～5 題測驗
- [ ] 展示至少一題「情境應用」題，而不只是背誦題

### 3. 完成測驗與複習排程
- [ ] 作答一題並展示答對／答錯結果
- [ ] 顯示解題說明
- [ ] 展示 FSRS-style 的下一次複習時間
- [ ] 說明 Again、Hard、Good、Easy 對排程的差異

### 4. LearnSight 學習時段
- [ ] 登入本機 YOLO/LearnSight 服務
- [ ] 建立學習目標與預計分鐘數
- [ ] 展示同步次數與「是否有人在畫面內」訊號
- [ ] 明確說明系統不保存影像、不做人臉辨識、不判定專注度
- [ ] 結束學習時段

### 5. 收尾
- [ ] 回到儀表板
- [ ] 展示學習內容、測驗結果與待複習項目
- [ ] 說明目前限制：部分資料層仍是 prototype，正式部署需加入後端與持久化資料庫

## 錄影前檢查

- [ ] 使用測試用 API key，不使用個人正式金鑰
- [ ] .env 沒有被錄入畫面或提交到 GitHub
- [ ] Gemini API 可以正常回應
- [ ] YOLO/LearnSight 服務已啟動
- [ ] 瀏覽器 Console 沒有明顯錯誤
- [ ] 準備一份固定教材，避免現場等待或生成結果不一致
- [ ] Demo 失敗時，準備截圖與預先生成的結果作為備援
